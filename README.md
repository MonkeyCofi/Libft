# Libft

## About
Libft is a library of a wide variety of recoded libc functions. On top of that, it has a bonus arsenal of linked list functions. A reimplementation of printf is also availabile within the library

To generate the library, run
```
make
```
or
```
make all
```

If you want to clean up the generated object files, run
```
make clean
```

To delete the generated library file along with the object files, run
```
make fclean
```

To regenerate the library, run
```
make re
```
